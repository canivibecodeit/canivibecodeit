Brand Positioning
Product: "Vibecode It?" (vibecodeit.com) — a free, open-source directory that answers one question per SaaS app: can you replace this paid subscription with one AI coding prompt? Think caniuse.com, but for killing your SaaS bills. Target audience: developers and indie hackers on Twitter/X who live in terminals and code editors. Positioning: cheeky but brutally honest — every YES verdict also lists what you lose. Tone adjectives: deadpan, utilitarian, mischievous, credible, fast. Comparables: caniuse.com's utilitarian data table, Mercury's serious data-dense directory, a terminal emulator. Avoid: corporate SaaS gloss, purple-blue gradients, glassmorphism, rounded friendly startup aesthetics, illustration mascots.

Aesthetic Concept
Core art direction in one phrase: "a phosphor terminal that files death certificates for SaaS subscriptions." A dark-mode-first, monospace-driven, dev-tool interface where the design language is a CRT terminal made rigorous: hairline borders, tabular data, uppercase micro-labels, blinking block cursor motifs. The memorable idea: verdicts rendered as loud traffic-light terminal badges (YES / KINDA / NOT REALLY) and a giant flaming-red "COLLECTIVE MRR DESTROYED: $4,218/mo" ticker counter styled like a stock-market readout. Intensity: restrained everywhere except the two anchors (verdict badges, MRR counter) — one intense color moment per page. Specific to this brand: every interactive element looks typed, not clicked; the search box is a command prompt.

Board Layout
One single 3840 x 2160 px, 16:9 landscape, high-quality 4K presentation image. Three full-height vertical columns with clean gutters on a neutral dark presentation background: LEFT 40% = page mockup 1 (homepage), MIDDLE 40% = page mockup 2 (app detail page), RIGHT 20% = design-system rail. The two page mockups dominate as large, inspectable, full-length desktop website pages. No extra panels, no device mockups, no moodboard imagery, no standalone logo explorations, no component inventories, no callout overlays, no decorative filler.

No logo notes, no spacing scales, no radii, no component lists.

Visual Style Constraints
Emphasize: hairline 1px borders, tabular monospace numerals, uppercase micro-labels with wide tracking, one intense color moment per page (green verdict on page 2, red ticker on page 1), calm generous dark whitespace, production-grade realism — this must look like a real shipped website, screenshot-ready. Avoid: gradients, glassmorphism, glow/bloom overdone, neon cyberpunk clutter, rounded friendly cards, stock illustrations, fake lorem ipsum (all visible copy must be plausible real copy), cramped layouts. Text must be crisp and readable; small text rendered accurately. The fixed three-column board layout applies strictly.
